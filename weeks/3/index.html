Week 3 cheat sheet

Workflow or agent

Definition

A workflow follows authored transitions; an agent can choose the next action within runtime limits.

Intuition

Use fixed control flow when the task's branches are known.

Pattern or formula

Keep policy checks outside the model and expose the actual control flow in traces.

Common mistake

Adding model autonomy does not make an otherwise fixed pipeline more reliable.

Production notes

Keep policy checks outside the model and expose the actual control flow in traces.

ReAct loop

Definition

A ReAct loop alternates a model's proposed action with an observed tool result.

Intuition

The runtime validates and executes actions; the model only proposes them.

Pattern or formula

Enforce tool budgets, deadlines, stop reasons and durable action identifiers.

Common mistake

Unbounded retries or treating a proposed action as permission creates unsafe behavior.

Production notes

Enforce tool budgets, deadlines, stop reasons and durable action identifiers.

Tool contract

Definition

A tool contract defines accepted inputs, permissions, outputs, effects and errors.

Intuition

An attempted operation and a confirmed effect are different states.

Pattern or formula

Use stable action IDs, reconciliation and structured error categories.

Common mistake

A timeout does not prove that an external write failed.

Production notes

Use stable action IDs, reconciliation and structured error categories.

MCP architecture

Definition

An MCP host uses clients to connect to servers that expose tools, resources and prompts.

Intuition

The protocol describes capabilities; the application still owns authorization.

Pattern or formula

Pin compatible SDK versions, validate schemas and enforce per-request scope.

Common mistake

A discovered tool is not automatically safe or permitted for every user.

Production notes

Pin compatible SDK versions, validate schemas and enforce per-request scope.

Agent state and memory

Definition

State records the current run; memory stores information that may be useful in later steps or runs.

Intuition

Separate temporary observations from durable, permission-scoped records.

Pattern or formula

Set retention rules and record the source and access scope of stored facts.

Common mistake

Storing every message can preserve stale facts, secrets and injected instructions.

Production notes

Set retention rules and record the source and access scope of stored facts.

Production architecture

Definition

Production architecture defines data, execution, policy and recovery boundaries.

Intuition

A deployed model is one component of a service with operational constraints.

Pattern or formula

Keep release gates, SLOs, canaries, rollback and incident evidence.

Common mistake

A successful demo does not establish capacity or recovery behavior.

Production notes

Keep release gates, SLOs, canaries, rollback and incident evidence.
