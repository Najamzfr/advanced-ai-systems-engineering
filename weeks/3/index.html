04 · Lectures / topics

LECTURE 3.1

An agent is a controlled state transition

Represent the run as structured state with explicit transitions. Validate proposed actions before execution, decrement budgets even on failures, and persist enough observations to reproduce behavior. Termination is an engineering condition, not a hopeful prompt.

LECTURE 3.2

Tools are typed trust boundaries

Timeout means the client does not know the outcome. Assign an idempotency key to the logical operation, query its status, and retry only under a documented contract. Keep authorization and numerical computation outside the model.

LECTURE 3.3

MCP connects capabilities, not permissions

A host owns the user interaction and permissions; each MCP client connects to a server exposing capabilities. Discovery does not grant authority. Validate schemas, identities, transport assumptions, and resource access independently.
