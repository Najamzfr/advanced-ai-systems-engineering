04 · Lectures / topics

LECTURE 7.1

Make work resumable

Persist workflow state before acknowledging an event. On restart, resume from a checkpoint and reconcile external effects using idempotency keys. Compensation is a new business action that offsets a completed effect, not a time reversal.

LECTURE 7.2

Trace a request across the platform

Carry a trace identifier across queue boundaries and link worker spans when parent-child timing is not appropriate. Attach model, prompt, corpus, and tool versions; redact content and secrets before export.

LECTURE 7.3

Deploy with an explicit rollback contract

Define an SLI at the user boundary and choose an SLO over a stated window. Canary by a limited cohort, compare errors and quality to baseline, and keep old prompts, indexes, and workflow versions available for rollback.
