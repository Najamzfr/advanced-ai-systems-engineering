WEEK 01 / 08

Foundation Models & Evaluation Science

Design a stratified evaluation dataset with held-out cases and reproducible model configurations.

Start this week20 planned hours

Overview

Follow the lessons in order. Each lesson includes its lecture, explanation, visual, relevant reading, exercise and quiz. Then complete the Weekly Build using the same experiment records in the capstone.

Learning objectives

  • Explain why fluent generation and valid JSON do not establish factual correctness.
  • Design controlled tests for reasoning, positional sensitivity, and model capability boundaries.
  • Turn raw failures into a versioned taxonomy and a frozen evaluation set.
  • Choose a metric that matches the task instead of reducing all quality to similarity.
  • Measure judge disagreement, order effects, and uncertainty without presenting scores as ground truth.
  • Build a capacity and cost argument for 500,000 monthly requests using measured quality.
  • Make the first project artifact reproducible before adding retrieval.

Week 1 cheat sheet

Output contract

Definition

A language model predicts tokens; the application must validate the resulting output.

Intuition

Treat generated text as an untrusted candidate result.

Pattern or formula

pi=exp⁡(zi/T)∑jexp⁡(zj/T)p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}

Common mistake

Schema validity does not prove factual correctness.

Production notes

Record model, prompt, decoding settings and validation failures.

Evaluation pipeline

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Pattern or formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.

LLM-as-a-Judge

Definition

A judge model applies a rubric to another model's output.

Intuition

The judge is a measurement instrument that needs calibration.

Pattern or formula

Precision=TPTP+FP,Recall=TPTP+FN\mathrm{Precision}=\frac{TP}{TP+FP},\qquad\mathrm{Recall}=\frac{TP}{TP+FN}

Common mistake

Agreement on mostly easy cases can hide missed failures.

Production notes

Keep human labels, judge revisions, order swaps and disagreements.

Model routing

Definition

A routing policy chooses a model using information available before the outcome is known.

Intuition

Measure the entire route, including retries and fallback calls.

Pattern or formula

Csuccess=Cinference+Cretrieval+Cretries+CoperationsNsuccessful tasksC_{\mathrm{success}}=\frac{C_{\mathrm{inference}}+C_{\mathrm{retrieval}}+C_{\mathrm{retries}}+C_{\mathrm{operations}}}{N_{\mathrm{successful\ tasks}}}

Common mistake

Knowing two models' average accuracy does not identify failures at request time.

Production notes

Trace route decisions, cost per successful task and tail latency.
