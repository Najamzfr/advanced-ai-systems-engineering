04 · Lectures / topics

LECTURE 1.1

A model is a stochastic component

Temperature rescales logits before sampling. A low-temperature answer can still be confidently wrong; evaluate correctness and uncertainty behavior separately. Hold prompt, output contract, and dataset fixed while varying decoding.

LECTURE 1.2

Measure the task, not the leaderboard

Define success at the task boundary, then stratify by failure cost and input type. Report per-slice counts as well as aggregate accuracy. Bootstrap paired per-example differences so improvements are compared on the same cases.

LECTURE 1.3

Calibrate judgment before scaling it

Use blinded candidate labels, swap response order, and compare judge outcomes with a human-labeled calibration subset. Track ties and disagreements; a persuasive rationale does not validate a verdict.
