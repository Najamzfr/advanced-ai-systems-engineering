Week 8 cheat sheet

Production architecture

Definition

Production architecture defines data, execution, policy and recovery boundaries.

Intuition

A deployed model is one component of a service with operational constraints.

Pattern or formula

Keep release gates, SLOs, canaries, rollback and incident evidence.

Common mistake

A successful demo does not establish capacity or recovery behavior.

Production notes

Keep release gates, SLOs, canaries, rollback and incident evidence.

Model routing

Definition

A routing policy chooses a model using information available before the outcome is known.

Intuition

Measure the entire route, including retries and fallback calls.

Pattern or formula

Csuccess=Cinference+Cretrieval+Cretries+CoperationsNsuccessful tasksC_{\mathrm{success}}=\frac{C_{\mathrm{inference}}+C_{\mathrm{retrieval}}+C_{\mathrm{retries}}+C_{\mathrm{operations}}}{N_{\mathrm{successful\ tasks}}}

Common mistake

Knowing two models' average accuracy does not identify failures at request time.

Production notes

Trace route decisions, cost per successful task and tail latency.

Evaluation pipeline

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Pattern or formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.

Customer intelligence system

Definition

A customer intelligence system turns permission-scoped data into reviewable recommendations.

Intuition

Prediction and an intervention's causal effect answer different questions.

Pattern or formula

Keep data lineage, deterministic calculations, approval records and recovery tests.

Common mistake

A sales correlation does not prove campaign uplift.

Production notes

Keep data lineage, deterministic calculations, approval records and recovery tests.
