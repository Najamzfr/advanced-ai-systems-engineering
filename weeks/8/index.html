04 · Lectures / topics

LECTURE 8.1

Degrade safely under pressure

Inject dependency failures with known scope and duration. Observe whether the system abstains, falls back, sheds load, or escalates. Recovery is successful only when invariants hold, including no duplicated consequential action.

LECTURE 8.2

Spend the error and token budgets deliberately

Route simple cases to cheaper models only when slice-level evaluation supports it. Cost per successful task includes retries, tools, retrieval, and human escalation. Show a Pareto comparison instead of optimizing one headline number.

LECTURE 8.3

Close the production feedback loop

Convert production failures into reviewed evaluation cases without leaking private data. Freeze the release test set; use new cases for the next cycle. Require a canary and rollback evidence before promoting the candidate.
