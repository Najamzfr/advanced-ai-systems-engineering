Week 6 cheat sheet

Model adaptation

Definition

Adaptation changes model behavior through training; retrieval supplies evidence at request time.

Intuition

Diagnose a knowledge problem separately from a behavior or serving problem.

Pattern or formula

ΔW=BA,Nadapter=r(din+dout)\Delta W=BA,\qquad N_{\mathrm{adapter}}=r(d_{\mathrm{in}}+d_{\mathrm{out}})

Common mistake

Training on poor or leaked examples can raise a score without improving the system.

Production notes

Track dataset lineage, splits, retention tests and adapter/model compatibility.

Evaluation pipeline

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Pattern or formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.

KV cache

Definition

A KV cache stores attention keys and values from tokens that have already been processed.

Intuition

Prefill creates cached state; decoding adds tokens to that state.

Pattern or formula

MKV=2LHKVdhb TNM_{\mathrm{KV}}=2L H_{\mathrm{KV}}d_h b\,T N

Common mistake

Ignoring sequence length or active concurrency understates memory demand.

Production notes

Use KV heads for grouped-query attention and include allocator and runtime overhead.

Inference serving

Definition

An inference service admits requests, schedules model execution and returns generated tokens.

Intuition

Queueing, prefill and decoding contribute different parts of latency.

Pattern or formula

TTFT=tfirst token−tarrival\mathrm{TTFT}=t_{\mathrm{first\ token}}-t_{\mathrm{arrival}}

Common mistake

Tokens per second alone does not establish the user's response-time target.

Production notes

Measure TTFT, completion latency, throughput, errors and memory under stated load.
