04 · Lectures / topics

LECTURE 6.1

Adapt behavior; retrieve changing knowledge

Fine-tuning can shape consistent behavior and task performance, while retrieval provides revision-aware evidence. Compare both and their combination. Test whether gains survive a temporal holdout and whether unrelated capabilities degrade.

LECTURE 6.2

Data is part of the model

Split by source or time before generating synthetic examples. Deduplicate across splits, record label provenance, and audit rare cases. Evaluate adapter changes on the same held-out tasks and keep training contamination out of conclusions.

LECTURE 6.3

Serving is a queueing and memory problem

Prefill processes prompt tokens; decode emits tokens incrementally using cached keys and values. Batching trades queue delay and memory for utilization. Report the load pattern and output-length distribution beside latency, not just a throughput maximum.
