04 · Lectures / topics

LECTURE 5.1

Evaluate the trajectory, not just the answer

A correct final response can hide unauthorized or wasteful tool calls. Record intent, selected tool, arguments, execution result, recovery, and final evidence. Evaluate intermediate contracts to localize regression.

LECTURE 5.2

Untrusted content crosses real boundaries

Treat retrieved pages, memory, and MCP responses as untrusted data. A policy gate validates identity, arguments, destination, and permissions before execution; a system prompt cannot enforce network or filesystem boundaries.

LECTURE 5.3

Reliability requires incident evidence

Compare the failing release against a known baseline using frozen inputs. Correlate model, prompt, index, data, and tool versions in traces. Separate mitigation that restores service from changes that prevent recurrence.
