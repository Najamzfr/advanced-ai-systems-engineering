Week 2 cheat sheet

Retrieval-augmented generation

Definition

A retriever selects source evidence for a generator to use when answering.

Intuition

The generator cannot cite evidence that retrieval never supplied.

Pattern or formula

Preserve source revision, access scope, passage IDs and exact evidence spans.

Common mistake

Semantic similarity does not establish the validity or freshness of a source.

Production notes

Preserve source revision, access scope, passage IDs and exact evidence spans.

Context engineering

Definition

Context engineering chooses the instructions, evidence, state and tools supplied to a model.

Intuition

The context window is a limited working space, not a permanent database.

Pattern or formula

Bevidence=W−Boutput−Bpolicy−Btask−BmemoryB_{\mathrm{evidence}}=W-B_{\mathrm{output}}-B_{\mathrm{policy}}-B_{\mathrm{task}}-B_{\mathrm{memory}}

Common mistake

Filling the window can crowd out useful evidence or exceed the output reserve.

Production notes

Version context assembly, enforce access rules and record truncation decisions.

Rank fusion and reranking

Definition

Fusion combines candidate lists; a reranker scores those candidates against the query.

Intuition

Candidate coverage and candidate ordering are separate decisions.

Pattern or formula

RRF⁡(d)=∑r∈R1k+rank⁡r(d)\operatorname{RRF}(d)=\sum_{r\in\mathcal{R}}\frac{1}{k+\operatorname{rank}_r(d)}

Common mistake

Raw scores from different retrievers are not automatically comparable.

Production notes

Log candidate IDs before and after each stage, and measure latency separately.

Document-tree retrieval

Definition

A document tree addresses evidence through document structure rather than only through vector chunks.

Intuition

Choose the right section before extracting the exact evidence span.

Pattern or formula

Compare tree, vector and long-context methods on the same questions and budget.

Common mistake

A tree-guided search can miss evidence when the hierarchy or routing is wrong.

Production notes

Compare tree, vector and long-context methods on the same questions and budget.
