04 · Lectures / topics

LECTURE 2.1

Retrieval is a ranking problem

Lexical retrieval captures identifiers and exact terminology; dense retrieval captures semantic neighborhoods. Fuse ranks before reranking, then measure whether relevant evidence survives each stage. Never infer answer quality from vector similarity alone.

LECTURE 2.2

Chunking changes the evidence unit

A chunk defines what can be retrieved, cited, and independently judged. Compare structural boundaries and parent-child expansion on fixed documents. Preserve offsets and document revisions so citations remain auditable.

LECTURE 2.3

Context is a bounded working set

Reserve room for instructions, tools, evidence, recent state, and output. Trim low-value material without deleting provenance or unresolved contradictions. Test evidence at beginning, middle, and end instead of assuming context capacity implies effective use.
