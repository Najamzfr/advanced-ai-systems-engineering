LAB 2 / WEEK 02

Retrieval Ablation Study

Find which retrieval change improves evidence coverage and final answers.

Objective

Find which retrieval change improves evidence coverage and final answers.

Prerequisites

Lab 1 harness; document corpus with stable IDs; relevance judgments.

Review Week 02 →

Architecture

Canonical lab brief

Compare:

  1. BM25
  2. vector retrieval
  3. hybrid retrieval
  4. hybrid + reranker
  5. long-context / no-RAG baseline

Metrics:

  • Recall@5
  • Recall@10
  • MRR
  • NDCG
  • context precision
  • answer correctness
  • latency
  • token cost

Implementation steps

  1. Step 01

    Ingest an immutable corpus snapshot. Retain source URLs, document revisions, offsets, timestamps, and access metadata.

  2. Step 02

    Create query-to-evidence relevance labels including identifier queries, multi-hop questions, and unanswerable cases. Split before tuning.

  3. Step 03

    Implement BM25, dense retrieval, reciprocal rank fusion, hybrid plus cross-encoder reranking, and a long-context baseline.

  4. Step 04

    Hold generator and prompt constant. Compare fixed, structural, and parent-child chunking separately from retrieval changes.

  5. Step 05

    Run oracle-context and retrieved-context generation. Attribute failures to missing evidence, ranking, context selection, or unsupported generation.

Experiment requirements

Run all five canonical baselines. Sweep retrieval depth and rerank depth; change one factor at a time. Measure middle-position evidence and irrelevant distractors.

Record dataset and code revisions, seeds, configuration, hardware, and per-case outcomes. Freeze test data before selecting the winning configuration. Report missing or blocked runs honestly.

Metrics

Recall@5; Recall@10; MRR; NDCG; context precision; answer correctness; latency; token cost.

Publish denominators and per-slice results. Use paired comparisons and uncertainty estimates where outcomes are stochastic.

Failure cases

Identifier mismatch; stale evidence; lost provenance; long-context truncation; contradictory sources; absent answer.

Deliverables

Relevance labels, frozen corpus manifest, five baseline configurations, paired ablation tables, and a deployment recommendation.

Stretch goals

Add HyDE or multi-query retrieval and justify extra calls using the same held-out set.
