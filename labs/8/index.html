LAB 8 / WEEK 08

Chaos Engineering for Agents

Demonstrate controlled degradation and defend the production design.

Objective

Demonstrate controlled degradation and defend the production design.

Prerequisites

Completed platform; Project 2 scenarios; baseline SLO and budget definitions.

Review Week 08 →

Architecture

Canonical lab brief

Break the system deliberately.

Test:

  • LLM unavailable
  • vector DB down
  • MCP server down
  • malformed model output
  • high latency
  • incorrect tool value
  • poisoned document
  • token budget exhausted
  • approval never arrives

Measure degradation.

Implementation steps

  1. Step 01

    Write invariants: no unauthorized action, no fabricated evidence, bounded execution, and no duplicate consequential effect.

  2. Step 02

    Create fault switches for model, vector store, MCP, malformed output, slow responses, wrong tool values, poisoned documents, budgets, and missing approval.

  3. Step 03

    Run each fault against a known-good baseline and record user-visible behavior plus traces.

  4. Step 04

    Exercise fallback, circuit breaker, load shedding, abstention, and recovery; verify rollback to a known version.

  5. Step 05

    Convert observed failures into regression cases and prepare a systems defense grounded in measured trade-offs.

Experiment requirements

Run single faults and at least one compound failure. Compare normal, degraded, recovered, and rolled-back states.

Record dataset and code revisions, seeds, configuration, hardware, and per-case outcomes. Freeze test data before selecting the winning configuration. Report missing or blocked runs honestly.

Metrics

SLO attainment; p95 latency; recovery time; task success; safe abstention; duplicate effects; tokens; cost per successful task.

Publish denominators and per-slice results. Use paired comparisons and uncertainty estimates where outcomes are stochastic.

Failure cases

Fallback repeats failure; model API down; stale index; silent wrong value; approval never arrives; exhausted budget.

Deliverables

Fault matrix, invariant checks, traces, recovery and rollback evidence, final platform, and oral-defense notes.

Stretch goals

Reduce cost by 50% in an experiment and quantify the resulting quality and latency change rather than assuming equivalence.
