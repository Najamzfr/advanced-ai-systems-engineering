WEEK 05 / WEEKLY BUILD

Red-team and repair the agent

One working system, measured against a fixed data pack. Estimated effort: 20–25 hours.

BUILD THE SYSTEM

A system can produce correct prose while still making unsafe tool calls or leaking information.

Deliverable. A before-and-after security report with at least 50 attacks and one verified mitigation.

DataFixed security attack packToolsAttack runner, permission policy, input/output validation, audit log, regression testsSourceCourse-owned cases with documented attack objectives

Start here

  1. Download the runnable starter

    Unzip it, then run make setup. Python and PowerShell equivalents are documented in the README.

  2. Run the smoke example

    Run make run. Read the denominators before interpreting any score.

  3. Fetch the assigned data

    Run the data script and verify the generated manifest before making a benchmark claim.

Worked example

  1. Run the smoke path

    Use make run and inspect reports/metrics.json.

    Expected: dataset: smoke_fixture, three cases, and a non-passing real-data status.

  2. Trace one failure boundary

    Open the project runtime and identify where malformed input, unavailable data, or a failed tool is recorded.

    Expected: one raw result, one explicit status, and one reproducible command.

  3. Run the real path

    Fetch the assigned data, run make evaluate, then run make grade.

    Expected: the grader passes only after the manifest, case count and required artifact are valid.
