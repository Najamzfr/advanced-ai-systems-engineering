WEEK 01 / INDEPENDENT ASSESSMENT

Defend your systems judgment.

Eight unseen scenarios. Draft your answers before revealing review criteria. These open-ended answers require self, peer, or instructor review.

Diagnostic quiz

Complete four automatically checked diagnostics, then write your answers to the eight independent scenarios below. The written defenses use a separate review rubric.

Code/output prediction

The model returns {"quantity":-3,"sku":"A17"}. JSON parsing succeeds. What happens next?

Multi-select

Select controls that make a pairwise judge more credible.

Sequencing

Put the release experiment in a defensible order.

Matching

Match each measurement to what it establishes.

This page saves drafts and rubric ratings; it does not automatically grade technical reasoning. Score each response 0 (missing/incorrect), 1 (partial), 2 (sound with a gap), or 3 (sound and justified). A suggested readiness threshold is 18/24, with no unresolved authorization or evidence-integrity errors. Ratings are self-reported unless you record an external reviewer.
SCENARIO 01 / 08

A structured response contains a well-formed but nonexistent invoice ID. Design the validation sequence before it reaches a customer.

Reveal the review criteria

Separate parse/schema checks from referential integrity and access scope; verify source/record existence; reject or escalate without inventing a replacement.

SCENARIO 02 / 08

At temperature zero, a model consistently gives the wrong answer to a long-context question. Design a controlled diagnostic with three evidence positions.

Reveal the review criteria

Keep content, length, model, and output budget fixed; move evidence beginning/middle/end; use correctness and citation checks; deterministic decoding is not confidence.

Review unit 1-2: Sampling experiments and reasoning reliability →

SCENARIO 03 / 08

A benchmark contains 40 questions from each of five documents. Explain why a random question split can overstate generalization and repair it.

Reveal the review criteria

Related source content leaks across splits; split documents first; preserve task coverage; uncertainty should account for document clustering.

Review unit 1-3: Error analysis before a metric →

SCENARIO 04 / 08

A code generator passes semantic similarity but fails an edge case involving an empty list. Redesign its quality gate.

Reveal the review criteria

Execute sandboxed functional tests including edge/adversarial cases; similarity is auxiliary; record compilation/runtime/failure types and preserve failing inputs.

Review unit 1-4: Exact, semantic, functional, and pairwise evaluation →

SCENARIO 05 / 08

A failure detector produces 24 alerts, 18 true failures, on a set with 30 human-labeled failures. Calculate precision and recall and explain release implications.

Reveal the review criteria

Precision 18/24=0.75; recall 18/30=0.60; twelve misses matter; calibrate against severity and slice requirements rather than relying on aggregate agreement.

Review unit 1-5: Calibrate a judge; quantify uncertainty →

SCENARIO 06 / 08

A judge favors candidate B 70% when B is first and 45% when B is second. Propose a scoring and audit procedure.

Reveal the review criteria

Blind identity, swap/randomize order, retain ties and invalid judgments, flag order flips, compare to adjudicated humans; do not average away unexplained bias.

Review unit 1-5: Calibrate a judge; quantify uncertainty →

SCENARIO 07 / 08

At illustrative prices $0.50/M input and $2/M output, requests average 1,000 input and 250 output tokens. Estimate 500,000 monthly requests with 20% full retries.

Reveal the review criteria

Base cost is $0.001/request or $500/month; 20% identical full retries gives $600 model cost; add infrastructure/retrieval/review and state length/rate assumptions.

Review unit 1-6: Cost, tail latency, and model selection →

SCENARIO 08 / 08

A provider update leaves average accuracy unchanged but doubles failures on unanswered questions. Define a regression gate and release response.

Reveal the review criteria

Version provider and evaluator, report the unanswered slice and abstention, use a hard slice threshold, canary/fallback or rollback, and preserve raw paired evidence.

Original curriculum defense prompts

  1. Why is temperature not equivalent to uncertainty?
  2. Why can average accuracy hide important production failures?
  3. When is pairwise evaluation preferable?
  4. What biases affect LLM judges?
  5. Why must latency and cost be evaluated alongside model quality?
  6. How would you detect a provider silently degrading model quality?

Review and next action

Independent review: not recorded

Revisit any weak unit, revise your answer, and ask a peer to challenge the assumptions. Retaking the same questions is review practice, not a fresh unseen test.

Artifact evidence · self-reported

Record the repository/release, reproduction command, result location and reviewer. This course does not inspect your external repository or certify these claims.
