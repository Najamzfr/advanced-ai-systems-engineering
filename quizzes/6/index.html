Defend your systems judgment.

Eight unseen scenarios. Draft your answers before revealing review criteria. These open-ended answers require self, peer, or instructor review.

This page saves drafts and rubric ratings; it does not automatically grade technical reasoning. Score each response 0 (missing/incorrect), 1 (partial), 2 (sound with a gap), or 3 (sound and justified). A suggested readiness threshold is 18/24, with no unresolved authorization or evidence-integrity errors. Ratings are self-reported unless you record an external reviewer.
SCENARIO 01 / 08

An assistant knows the right facts when given evidence but fails to follow a stable output convention. Design the intervention order.

Reveal the review criteria

Diagnose behavior; compare clear schema/instructions and examples before adaptation; use LoRA only with held-out gains; retrieval alone does not solve stable behavior mismatch.

SCENARIO 02 / 08

A synthetic training set includes paraphrases of held-out questions. How should the experiment be repaired?

Reveal the review criteria

Remove leakage/near duplicates, split original sources before generation, regenerate training-only variants, keep a fresh untouched test set and report contamination.

Review unit 6-2: Dataset engineering for adaptation →

SCENARIO 03 / 08

Compute LoRA parameters for a 2,048×4,096 matrix at rank 16 and explain what the calculation excludes.

Reveal the review criteria

16×(2048+4096)=98,304; excludes base weights, activations, optimizer state and other adapted matrices; low trainable count is not total memory.

Review unit 6-3: SFT, LoRA, QLoRA, and forgetting →

SCENARIO 04 / 08

LoRA+RAG wins on answer accuracy but worsens general instruction following. How should the six-condition study report and decide?

Reveal the review criteria

Report all six fixed conditions, retention and task slices, resource/update costs; check hard thresholds and uncertainty; domain gain does not excuse unmeasured forgetting.

Review unit 6-4: The required six-way adaptation study →

SCENARIO 05 / 08

A model has 24 layers, 8 KV heads, dimension 128, 2-byte elements and 2,048 retained tokens. Estimate KV per sequence.

Reveal the review criteria

2×24×8×128×2×2048=201,326,592 bytes=192 MiB; multiply across active sequences and add overhead/other memory.

Review unit 6-5: Prefill, decode, and KV-cache accounting →

SCENARIO 06 / 08

Quantization saves memory but a rare numeric task degrades. What release comparison should accompany the serving benchmark?

Reveal the review criteria

Same representative workload/model family, quality/retention slices, precision/kernel config, memory/latency/throughput and paired failures; reject if quality gate fails.

Review unit 6-6: Continuous batching and serving optimization →

SCENARIO 07 / 08

Speculative decoding has a low draft acceptance rate and is slower than baseline. Explain the likely mechanism.

Reveal the review criteria

Draft compute plus target verification overhead outweighs accepted-token savings; measure acceptance and timing by workload, tune or remove it rather than assuming universal speedup.

Review unit 6-6: Continuous batching and serving optimization →

SCENARIO 08 / 08

A report promises 100 requests/s and p95<2s based on a single unloaded request. List the minimum missing evidence.

Reveal the review criteria

Define TTFT vs completion, input/output lengths, hardware/model/precision, arrival/concurrency mix, steady-state and overload tests, failures/headroom and quality; label extrapolation not achievement.
