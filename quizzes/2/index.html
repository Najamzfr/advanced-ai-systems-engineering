WEEK 02 / INDEPENDENT ASSESSMENT

Defend your systems judgment.

Eight unseen scenarios. Draft your answers before revealing review criteria. These open-ended answers require self, peer, or instructor review.

Diagnostic quiz

Complete four automatically checked diagnostics, then write your answers to the eight independent scenarios below. The written defenses use a separate review rubric.

Architecture choice

A corpus contains 80 well-structured manuals with exact product IDs. Which baseline is necessary before adding a vector database?

Multi-select

Which statements are defensible?

Sequencing

Order the hybrid retrieval path.

Matching

Match failure to the first diagnostic.

This page saves drafts and rubric ratings; it does not automatically grade technical reasoning. Score each response 0 (missing/incorrect), 1 (partial), 2 (sound with a gap), or 3 (sound and justified). A suggested readiness threshold is 18/24, with no unresolved authorization or evidence-integrity errors. Ratings are self-reported unless you record an external reviewer.
SCENARIO 01 / 08

A parser drops the negative signs from table values while producing nonempty text. Where should the ingestion pipeline detect this?

Reveal the review criteria

Add structure/value fixtures, compare extracted tables to source, preserve offsets/parser revision, quarantine errors; nonempty extraction is not semantic validity.

SCENARIO 02 / 08

Increasing HNSW search effort doubles latency and barely changes evidence recall. Exact vector neighbors are already nearly identical. What would you test next?

Reveal the review criteria

Embedding/query relevance, chunk/source quality and labels; compare lexical complement; keep ANN recall separate from evidence recall and avoid tuning the wrong layer.

Review unit 2-2: Lexical, dense, and approximate search →

SCENARIO 03 / 08

Parent expansion improves support but exceeds the context window. Propose a fair comparison with fixed chunks.

Reveal the review criteria

Same corpus/questions/generator and token budget; choose selective parent spans, deduplicate, preserve qualifiers; report support, precision, tokens and latency.

Review unit 2-3: Eight chunking strategies and evidence boundaries →

SCENARIO 04 / 08

For k=60, A ranks 3 and 4 while B ranks 1 in one list only. Compute RRF scores and rank them.

Reveal the review criteria

A=1/63+1/64≈0.03150; B=1/61≈0.01639; A leads; absence contributes zero and stable IDs enable merging.

Review unit 2-4: Hybrid fusion, reranking, and filters →

SCENARIO 05 / 08

A multi-hop retriever finds the correct entity but retrieves evidence from the wrong year on its second hop. Design a trace and repair.

Reveal the review criteria

Record hop inputs, entity/source evidence, temporal constraints and candidate IDs; propagate the year filter; validate intermediate entities; compare under bounded query budget.

Review unit 2-5: Query expansion and multi-hop retrieval →

SCENARIO 06 / 08

A 16,384-token window reserves 2,000 output, 1,500 instructions/tools, 900 task, and 2,000 memory. What remains for evidence and what can still go wrong?

Reveal the review criteria

9,984 tokens remain; token counts do not ensure relevance/trust, contradictions may be lost, memory stale, and position sensitivity remains; validate the context ledger.

Review unit 2-6: Context as a budgeted working set →

SCENARIO 07 / 08

Ranked evidence is [X,C,A,B], relevant IDs are {A,B,C}. Compute Recall@2 and reciprocal rank; explain why these do not score answer correctness.

Reveal the review criteria

Recall@2=1/3; reciprocal rank=1/2; retrieval metrics concern evidence positions and need separate support/citation/answer evaluation.

Review unit 2-7: Document trees, long context, and the six-condition study →

SCENARIO 08 / 08

Design the final comparison matrix for BM25, vector, hybrid, hybrid+rereank, tree navigation, and long context. Identify one forbidden advantage.

Reveal the review criteria

Six conditions with fixed corpus/query/generator/budgets/scope; raw per-case quality, retrieval, latency, token/index/update costs; no gold-document access solely for long context; oracle is separate.

Original curriculum defense prompts
