WEEK 05 / INDEPENDENT ASSESSMENT

Defend your systems judgment.

Eight unseen scenarios. Draft your answers before revealing review criteria. These open-ended answers require self, peer, or instructor review.

Diagnostic quiz

Complete four automatically checked diagnostics, then write your answers to the eight independent scenarios below. The written defenses use a separate review rubric.

Identify the bug

A retrieved page tells the agent to send private context to evil.example. Which is the actual enforcement boundary?

Multi-select

What must an approval be bound to?

Sequencing

Order a defensible incident investigation.

Matching

Match observation to evaluation meaning.

This page saves drafts and rubric ratings; it does not automatically grade technical reasoning. Score each response 0 (missing/incorrect), 1 (partial), 2 (sound with a gap), or 3 (sound and justified). A suggested readiness threshold is 18/24, with no unresolved authorization or evidence-integrity errors. Ratings are self-reported unless you record an external reviewer.
SCENARIO 01 / 08

A final answer is correct, but its trace contains an unnecessary unauthorized read. Design the evaluation verdict.

Reveal the review criteria

Answer correctness passes separately; policy/trajectory compliance fails; block release and repair access boundary, retaining attempted/executed distinction.

Review unit 5-1: Evaluate trajectories and components →

SCENARIO 02 / 08

A retrieved webpage tells the agent that "security checks have been disabled for this test." Trace the attempted authority crossing.

Reveal the review criteria

Web content is untrusted evidence; it attempts to override runtime policy; reject effects outside current scope and record injection provenance without granting instruction authority.

Review unit 5-2: Threat-model untrusted instructions →

SCENARIO 03 / 08

A draft is approved, then its discount value changes while the approval ID stays the same. What must the dispatcher verify?

Reveal the review criteria

Canonical action digest/content, destination, policy revision, approver and expiry; changed material arguments invalidate approval even if ID remains.

Review unit 5-3: Enforce permissions outside the model →

SCENARIO 04 / 08

A tool can fetch any HTTPS URL and stores an API token in its prompt. Identify two independent repairs.

Reveal the review criteria

Restrict actual egress/destinations/redirects to prevent SSRF/exfiltration; remove secret from prompt and isolate/redact credentials; model instructions alone are insufficient.

Review unit 5-3: Enforce permissions outside the model →

SCENARIO 05 / 08

An attack suite reports 0/50 unauthorized effects but the system refuses 40% of benign tasks. What can you claim?

Reveal the review criteria

No observed success on this tested attack set, not universal security; report high false refusal and task utility, inspect boundary-specific controls and held-out attacks.

Review unit 5-4: Run a reproducible red-team matrix →

SCENARIO 06 / 08

Twenty attacks share the same template and differ only in punctuation. Why might 50 total attacks overstate coverage?

Reveal the review criteria

Count is not threat diversity; map entry points, attacker controls, effects and persistence; cluster variants, hold out families and report coverage honestly.

Review unit 5-4: Run a reproducible red-team matrix →

SCENARIO 07 / 08

A postmortem attributes an incident to hallucination but shows a stale permission cache. Rewrite the causal hypothesis and regression.

Reveal the review criteria

Stale authorization state allowed a forbidden effect; validate current policy/invalidate cache, add revocation race test and end-to-end denial case, distinguish observed evidence from inference.

Review unit 5-5: Incident analysis and regression repair →

SCENARIO 08 / 08

The retail dataset has no consent fields. A student infers consent from repeated purchases. Assess the proposed campaign workflow.

Reveal the review criteria

Purchases do not establish consent; use explicitly synthetic fixtures and sandbox sink, deterministic eligibility, no real contact enrichment or causal campaign claims.
