The gateway validates identity and request shape, enforces rate and budget limits, and chooses a synchronous or queued path. Cache keys include model/prompt, relevant data and policy revisions, and access scope. Do not reuse another tenant's evidence because the question text matches. Separate state storage from derived indexes so a rebuild does not erase workflow history.

Queues absorb bursts but move waiting time rather than eliminating it. Bound queue depth and age; reject or degrade when the system cannot meet its promise. Fallback must satisfy the same output and security contracts as the primary provider. Store secrets outside source, validate configuration on startup, and use feature flags with explicit rollback behavior.

Service boundaries

Study:

API gateway
Authenticate requests and apply admission controls before work enters the application.
Model gateway
Centralize model-provider calls, accounting and request policy behind a consistent interface.
Model router
Select the permitted model or fallback for a task using a measured decision policy.
Semantic cache
Reuse meaning-equivalent answers only when tenant, permissions, data revision and freshness also match.
Rate limiter
Limit accepted requests or tokens over time to control abuse and protect capacity.
Queues
Buffer pending work with bounded capacity, deadlines and explicit delivery semantics.
Persistence
Store the state needed for restart, audit and reconciliation rather than relying on process memory.
Provider fallback
Switch providers only when the alternative meets the task's quality, privacy and output requirements.
Secrets
Keep credentials out of prompts and logs, and grant them only to the component that needs them.
Feature flags
Control exposure to changed behavior and retain a tested path back to the earlier behavior.
Canary
Expose a limited traffic slice to a new version and compare declared release metrics.
Rollback
Restore a known version and account for any data or external effects the failed version already produced.

Work through an example

A cached answer includes customer-specific pricing. A key made only from the question leaks across customers. Include authorization scope and data revision, or avoid caching that response when safe partitioning cannot be established.
