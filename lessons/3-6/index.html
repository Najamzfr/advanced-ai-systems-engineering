Task state contains the goal, pending actions, evidence references, completion status, and remaining budgets. Memory supplies selected history, not unlimited conversation. Serialize state deliberately: a framework's opaque message history is insufficient for replay or audit. Separate tool observations from trusted instructions and preserve the source revision behind summaries.

After the scratch implementation passes contracts, port one representative flow to one framework. Compare traces on identical fixtures: same tool permissions, output schema, timeout/retry behavior, and stop conditions. Framework defaults may differ in retry count, schema coercion, parallel tool execution, and error handling. An abstraction is acceptable when those behaviors remain inspectable and controlled.

Bounded agent loop

Work through an example

The scratch loop stops after three tool calls; a framework silently retries invalid model output twice per step. The apparent three-step budget now hides additional inference calls. Track provider calls and tokens as well as visible agent steps.

Cheat sheet

State, memory, and framework equivalence

Definition

State records the current run; memory stores information that may be useful in later steps or runs.

Intuition

Separate temporary observations from durable, permission-scoped records.

Pattern

Publish a scratch-versus-framework trace comparison and explain every behavioral difference.

Common mistake

Storing every message can preserve stale facts, secrets and injected instructions.

Production notes

Set retention rules and record the source and access scope of stored facts.
