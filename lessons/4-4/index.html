Coordination adds failures absent from a single model call. Workers can wait cyclically, repeat identical searches, disagree on schema, exhaust a shared budget, or overwrite evidence. Distinguish useful disagreement from malformed output. A merge policy should preserve contradictions and missing workers rather than converting partial completion into success.

Use task IDs, leases/deadlines, explicit statuses, bounded queues, and a single budget ledger. Keep provenance when merging evidence and isolate untrusted tool text from worker instructions. Detect repeated subtask creation and unproductive cycles. When a worker fails, determine whether the output can safely be partial or requires escalation. Recovery should preserve completed evidence without rerunning every task.

Coordination failures

context isolation

Communication overhead
Count messages, serialization and extra model calls when judging whether more agents help.
Cascading errors
An early incorrect result can contaminate later tasks unless downstream checks reject it.
Coordination failures
Workers can duplicate work or wait indefinitely when ownership and dependencies are unclear.
Deadlocks
Detect cycles where tasks wait on one another and cannot make progress.
Disagreement
Keep conflicting evidence visible until a verifier can resolve or report the uncertainty.
Consensus
Agreement among agents can reflect shared errors, so it still needs an independent correctness check.
Failure propagation
Mark dependent tasks blocked or incomplete instead of allowing them to consume invalid results.
Debugging complexity
Retain task identities, messages and state transitions so an error can be traced across workers.

Cheat sheet

Coordination failure and recovery

Definition

A multi-agent system divides work among model-driven components with explicit handoffs.

Intuition

Coordination is another source of latency and failure.

Pattern

Inject missing workers, schema mismatch, duplicate subtasks, contradictory evidence, and exhausted budget into the comparison harness.

Common mistake

More agents can amplify the same error instead of providing independent verification.

Production notes

Give each role a contract, owner, budget and observable failure path.
