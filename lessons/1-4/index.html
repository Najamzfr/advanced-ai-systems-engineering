Exact checks suit canonical IDs and deterministic values after declared normalization. Semantic similarity can identify paraphrases but cannot prove a number, negation, or citation is correct. Functional evaluation executes an output in a controlled environment and checks behavior. Task metrics measure what matters: supported claims, eligible actions, or resolved questions.

Pairwise evaluation compares two outputs on the same task under a fixed rubric and allows ties. Blind candidate identity and randomize order. Report wins, losses, ties, and invalid judgments with denominators; do not drop failures. Keep retrieval Recall@K separate from end-to-end answer quality so you know which component changed. Evaluation-driven development is a loop: inspect failures, propose a mechanism, change one component, then rerun frozen comparisons.

Work through an example

A generated SQL query differs from the reference string but returns the correct rows on adversarial fixtures. Exact string matching penalizes it incorrectly; execution tests are stronger. Conversely, "revenue increased 12%" and "revenue decreased 12%" can be semantically close while contradicting one another.

Read the explanation

Exact/typed date and ID checks catch format and value errors but not argument quality. Source-support review checks cited evidence but may miss omitted contradictions. A calibrated semantic or pairwise rubric evaluates explanation quality but can be biased. Keep the results separate.

Cheat sheet

Exact, semantic, functional, and pairwise evaluation

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Declare the relevant set, retrieval unit and query denominator. Candidate recall is not answer accuracy.

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.
