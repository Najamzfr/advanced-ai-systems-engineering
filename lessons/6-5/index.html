Prefill processes prompt tokens and constructs attention keys and values. Decode generates one new token per sequence per iteration, reusing cached states. Time to first token includes queueing and prefill; total response latency also includes decode. Inter-token latency measures streaming pace, while throughput measures tokens or requests completed over time. Report input/output length distributions because they determine workload.

Approximate KV storage is 2×layers×KV_heads×head_dimension×bytes_per_element×retained_tokens across active sequences. Grouped-query attention reduces KV heads relative to query heads. Prefix caching reuses compatible prefix state only when model, tokens, cache format, and scope allow it; it is distinct from caching a complete answer. Memory pressure grows with long active sequences even when model weights fit.

KV cache and continuous batching

MKV=2LHKVdhb TNM_{\mathrm{KV}}=2L H_{\mathrm{KV}}d_h b\,T N

L is the number of layers, H is the number of KV heads, d is head dimension, b is bytes per element, T is retained tokens and N is active sequences. This estimate excludes other model and runtime memory.

Inspect KV memory growth

Illustrative accounting, excluding allocator overhead, weights, activations and other state.

Work through an example

For 32 layers, 8 KV heads, head dimension 128, and 2-byte elements, KV costs 131,072 bytes per token. At 4,096 tokens that is 512 MiB per sequence; eight such sequences need about 4 GiB before allocator overhead and other memory. This is an illustrative model configuration.

Cheat sheet

Prefill, decode, and KV-cache accounting

Definition

A KV cache stores attention keys and values from tokens that have already been processed.

Intuition

Prefill creates cached state; decoding adds tokens to that state.

Formula

MKV=2LHKVdhb TNM_{\mathrm{KV}}=2L H_{\mathrm{KV}}d_h b\,T N

L is the number of layers, H is the number of KV heads, d is head dimension, b is bytes per element, T is retained tokens and N is active sequences. This estimate excludes other model and runtime memory.

Common mistake

Ignoring sequence length or active concurrency understates memory demand.

Production notes

Use KV heads for grouped-query attention and include allocator and runtime overhead.
