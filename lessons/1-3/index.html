Begin with representative tasks and the decision the system should support. Inspect complete input, retrieved evidence, tool results, output, and expected behavior. Label the earliest actionable failure: missing evidence, wrong evidence selection, unsupported synthesis, malformed output, forbidden action, or infrastructure failure. Allow secondary tags without counting the same case multiple times in overall task success.

Build a development set for iteration and a held-out set for comparison. Split by source, customer, or time when related examples can leak; random row splits are insufficient for near duplicates. Define each label with positive examples, counterexamples, and an adjudication rule. Rare but severe cases need their own slice even if the aggregate improves. Keep human disagreements: they expose ambiguous tasks and rubrics.

Evaluation pipeline

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Declare the relevant set, retrieval unit and query denominator. Candidate recall is not answer accuracy.

Work through an example

An answer cites a real paragraph that discusses the wrong product revision. Retrieval found the product but missed the requested date; generation then overclaimed. Label retrieval temporal mismatch as primary and unsupported claim as secondary. A human label "bad answer" would hide the specific repair.

Exercise

Apply the explanation

Your dataset has 900 easy FAQs and 100 permission-sensitive requests. The new model gains 20 FAQ successes and loses 10 permission checks. How should the report expose the change?

Read the explanation

Report overall paired change and both slices. The +1 percentage-point aggregate masks a 10-point permission regression. Use a separate hard security gate; do not trade unauthorized behavior for FAQ gains.

Cheat sheet

Error analysis before a metric

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Declare the relevant set, retrieval unit and query denominator. Candidate recall is not answer accuracy.

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.
