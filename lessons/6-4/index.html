Required conditions are zero-shot, few-shot, advanced prompting, RAG, LoRA, and LoRA plus RAG. Reuse one frozen task split, model family, output contract, and evaluation harness. Define "advanced prompting" concretely: structured task instructions, evidence requirements, and a validated response schema, for example. Select demonstrations and hyperparameters on development data only.

Record data preparation, training cost, retrieval cost, inference latency, quality, retention, and operational update burden. Separate gains from adding evidence versus changing behavior. Use a small model and bounded adapter run to make the experiment feasible. If hardware is unavailable, analyze a clearly labeled supplied or self-recorded trace; mark execution competency unverified and never present simulated values as measurements. The six-condition coverage remains required.

Work through an example

LoRA improves format compliance from 85% to 97% but answer grounding remains 70%. RAG improves grounding to 89%; the combination reaches 90% with higher latency. The decision depends on whether the extra percentage point and formatting gain meet the actual task requirements.

Exercise

Apply the explanation

The RAG condition uses a newer model than zero-shot, and LoRA gets twice the output budget. Can the gains be attributed to technique?

Read the explanation

No. Control model and budget or label those differences as additional factors. A matched comparison is needed to isolate adaptation and retrieval effects.

Cheat sheet

The required six-way adaptation study

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Declare the relevant set, retrieval unit and query denominator. Candidate recall is not answer accuracy.

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.
