For a local server, stdio uses process input/output; protocol messages must not be mixed with ordinary debug output. Send diagnostics to stderr. For remote access, StreamableHTTP adds network lifecycle, authentication, origin handling, session behavior, and cancellation concerns. Transport success is different from successful domain execution.

Validate tool schemas and results at both ends. Restrict file paths after canonicalization and reject traversal outside the allowed directory. MCP roots describe an intended scope; they are not an operating-system sandbox. Server code and filesystem permissions enforce the actual boundary. Keep credentials outside model context, verify intended token audience where applicable, and never pass arbitrary untrusted URLs to a privileged fetcher. Test timeout, malformed response, denied path, and disconnected server separately.

Work through an example

A roots list allows /research. A tool argument /research/../secrets is still unsafe unless the server resolves the real path and checks containment, including symlinks. Treat the list as a policy input, not a guarantee that the operating system will stop access.

Cheat sheet

Implement and test an MCP connection

Definition

An MCP host uses clients to connect to servers that expose tools, resources and prompts.

Intuition

The protocol describes capabilities; the application still owns authorization.

Pattern

Finish Lab 3B with both a local round trip and a documented remote transport/auth design; keep errors visible in the host.

Common mistake

A discovered tool is not automatically safe or permitted for every user.

Production notes

Pin compatible SDK versions, validate schemas and enforce per-request scope.
