Least privilege means a tool can access only the data and actions needed for the current task. Validate caller identity, resource scope, argument ranges, destination allowlists, and current policy at execution time. Constrain URL fetches against SSRF with scheme/host/IP controls and redirect checks; a model's chosen URL is untrusted input. Keep credentials out of prompts and redact logs.

Consequential actions require approval bound to exact content, destination, policy revision, approver, and expiry. Hash a canonical action representation; any material change invalidates the approval. Approval is a durable policy record, not the presence of "yes" in chat. Sandbox external effects in course projects and make rejection observable.

Cheat sheet

Enforce permissions outside the model

Definition

A trust boundary separates data the system may inspect from instructions it is authorized to execute.

Intuition

Retrieved documents and tool output remain untrusted data.

Formula

ASR=Nattacks achieving the forbidden objectiveNattempted attacks\mathrm{ASR}=\frac{N_{\mathrm{attacks\ achieving\ the\ forbidden\ objective}}}{N_{\mathrm{attempted\ attacks}}}

Define the forbidden effect before testing. Report benign task success separately from attack success rate.

Common mistake

A safe final answer does not cancel an unauthorized tool effect.

Production notes

Enforce least privilege, human approval and output checks at execution time.
