Calibrate a judge; quantify uncertainty

A judge is a model-dependent measurement instrument. Calibrate it on adjudicated human labels. Write a task-specific rubric with anchored examples and permitted ties; require evidence references. Hide provider identity, swap answer order, and inspect verbosity and self-preference effects. If a verdict flips when order flips, flag instability instead of silently choosing the preferred orientation.

For binary labels, examine true/false positives and negatives at a chosen threshold. Agreement alone can look high when failures are rare, so report class-specific precision and recall. For paired system comparisons, resample task IDs with replacement and compute the difference on the same sampled IDs. A percentile bootstrap interval estimates sampling uncertainty under its assumptions; it does not fix unrepresentative data, leakage, or correlated sources. Cluster by source when questions share a document.

LLM-as-a-Judge calibration

Precision=TPTP+FP,Recall=TPTP+FN\mathrm{Precision}=\frac{TP}{TP+FP},\qquad\mathrm{Recall}=\frac{TP}{TP+FN}

Here the positive class is a failure. Precision measures valid alerts; recall measures the failures detected. Undefined denominators need an explicit reporting rule.

Evaluation requirements

evaluation-driven development

Exact evaluation
Compare an answer with a specified reference after only the normalization permitted by the task.
Semantic evaluation
Assess whether meaning matches the reference while checking that extra claims remain supported.
Functional correctness
Execute tests or verify invariants to determine whether an output performs the required task.
Task-specific metrics
Choose measurements that reflect the application's decisions and failure costs.
Pairwise evaluation
Compare two outputs for the same input with a fixed rubric and randomized presentation order.
LLM-as-a-judge
A model applies an evaluation rubric; validate its judgments against human-reviewed cases.
Judge bias
A judge may favor style, model identity or presentation instead of the required quality criteria.
Position bias
Swap candidate order to test whether a judge favors the first or second answer.
Verbosity bias
Compare equally correct answers of different lengths to test whether extra words inflate scores.
Judge calibration
Measure agreement and error types against adjudicated labels before using a judge for release decisions.
Human evaluation
Reviewers apply a shared rubric and resolve disagreements with documented evidence.
Regression testing
Rerun frozen cases after changes to detect failures in previously working behavior.
Adversarial cases
Deliberately difficult inputs test a specified failure boundary rather than typical average behavior.
Confidence intervals
Report a range that reflects sampling uncertainty, with the estimation method and sample size.
Cost
Include model calls, retrieval, infrastructure and human work in the cost of a completed task.
Latency
Measure elapsed time across the whole request and its components, including queueing and retries.

Work through an example

A judge flags 18 failures: 12 are true failures and 6 are false alarms. Humans found 20 failures total. Precision=1218≈0.667,Recall=1220=0.60\mathrm{Precision}=\frac{12}{18}\approx0.667,\quad\mathrm{Recall}=\frac{12}{20}=0.60. Overall agreement on a mostly easy dataset could still be high. The eight missed failures deserve error analysis before automated gating.

Apply the explanation

A 95% interval for paired accuracy improvement spans −2 to +5 percentage points. Can you claim a reliable improvement? What extra evidence matters?

Read the explanation

The interval includes no change and degradation. Report inconclusive evidence, inspect slice behavior and cost, and collect representative independent cases if needed. Do not repeatedly test on the held-out set until significance appears.

Cheat sheet

Calibrate a judge; quantify uncertainty

Definition

A judge model applies a rubric to another model's output.

Intuition

The judge is a measurement instrument that needs calibration.

Formula

Precision=TPTP+FP,Recall=TPTP+FN\mathrm{Precision}=\frac{TP}{TP+FP},\qquad\mathrm{Recall}=\frac{TP}{TP+FN}

Here the positive class is a failure. Precision measures valid alerts; recall measures the failures detected. Undefined denominators need an explicit reporting rule.

Common mistake

Agreement on mostly easy cases can hide missed failures.

Production notes

Keep human labels, judge revisions, order swaps and disagreements.
