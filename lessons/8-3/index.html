Production-like traces suggest where to look; they are not automatically ground truth. Sample failures and representative successes, redact data, reconstruct the task, and obtain labels with an explicit rubric. Preserve consent/access requirements and separate user feedback from independently verified correctness. A thumbs-up can reflect politeness or usefulness rather than factual support.

Add new failures to a regression set without repeatedly tuning on the final held-out set. Compare a candidate with the current release under the same cases and budgets. Track prompt, model, tool, policy, and data versions so a gain can be attributed. Roll out with measured gates, monitor slices, and retain a rollback path. The loop is inspect→label→hypothesize→experiment→review→release.

Work through an example

Traces show frequent "missing consent" escalations. Inspection reveals a fixture-import bug, not an overcautious model. Repair data ingestion and add a regression; changing the prompt to assume consent would turn a data defect into a policy violation.

Cheat sheet

Close the telemetry-to-evaluation loop

Definition

An evaluation compares versioned outputs with a task-specific definition of success.

Intuition

Measure the component that could cause the observed failure.

Formula

Recall@K⁡=∣relevant∩top K∣∣relevant∣\operatorname{Recall@K}=\frac{|\mathrm{relevant}\cap\mathrm{top}\ K|}{|\mathrm{relevant}|}

Declare the relevant set, retrieval unit and query denominator. Candidate recall is not answer accuracy.

Common mistake

A higher aggregate score can hide a regression on a critical slice.

Production notes

Freeze case IDs and report denominators, uncertainty and failed runs.
