Metrics aggregate behavior over time; logs capture discrete events; traces connect spans for one execution. Start an API span, propagate trace context through queued work or link asynchronous executions when parent lifetimes differ, then create retrieval, model, tool, verification, and dispatch spans. Record queue delay separately from worker processing.

Attach bounded-cardinality attributes such as operation, outcome, release, model, and tool version. Put unique run IDs in traces/logs rather than unbounded metric labels. Record tokens, latency, retries, policy outcomes, and safe error codes. Redact prompts, credentials, and personal data; observability should not become a second data leak. Sampling can hide rare failures, so retain enough error evidence and document sampling policy.

Tracing requirements

Study:

Logs
Record discrete events with identifiers and redaction so an incident can be reconstructed.
Metrics
Aggregate measurements over time with bounded label cardinality and clear units.
Traces
Connect the operations belonging to one request or workflow so delays and failures can be localized.
Spans
Record an individual operation's start, end, status and relationship to other operations.
OpenTelemetry
Use standard instrumentation and context propagation to export traces, metrics and logs.
Distributed tracing
Propagate correlation context across services and queues to reconstruct a request's work.
Model calls
Record model revision, duration, usage and status without unnecessarily storing sensitive prompt content.
Tool calls
Record tool identity, validation outcome and effect status with sensitive arguments redacted.
Latency
Measure elapsed time across the whole request and its components, including queueing and retries.
Token use
Count input, output and retried model tokens against the task that incurred them.
Retries
Repeat transiently failed work within limits after checking whether the earlier attempt may have succeeded.
Failures
Classify failed operations by cause and effect status so retry and release decisions use the right evidence.
Cost attribution
Assign expenses to a task, customer or experiment, including retries and failed attempts.
SLA
An external service agreement states promised behavior and the consequences of missing it.
SLO
An internal target sets the acceptable level of a defined service indicator over a stated window.

Cheat sheet

OpenTelemetry across asynchronous work

Definition

Observability connects logs, metrics and traces to the system's requests and decisions.

Intuition

A trace should explain where time, cost and failure entered a request.

Pattern

Export one complete trace, a latency/error dashboard, and a redaction test; attribute cost by stage and release.

Common mistake

A missing parent-child link can make queueing or worker delays invisible.

Production notes

Record span links, revisions and policy outcomes while redacting secrets.
