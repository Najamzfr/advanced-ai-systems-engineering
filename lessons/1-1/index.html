An autoregressive model predicts the next token from a prefix. A transformer converts that prefix into contextual representations, projects them to logits, and decoding chooses a token. Repeating the process creates a sequence; it does not look up an independently verified answer. Tokenization affects length, cost, and identifiers. The context window bounds the input plus generated output, not the amount of evidence the model reliably uses.

Token selection can make an output more or less variable, but it cannot verify a claim. The next lesson tests those sampling choices under a controlled budget. Constrained generation can prevent syntactically invalid choices. After decoding, application code must still validate schema, ranges, identifiers, and evidence. A valid object can contain a fabricated citation.

How tokens share information

Attention forms a representation of each token using information from other token positions. Query and key vectors determine weights; those weights combine the value vectors. A causal mask prevents a position from reading later tokens during autoregressive prediction.

Attention⁡(Q,K,V)=softmax⁡ ⁣(QKTdk+M)V\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}+M\right)V

The mask M contains zero for allowed positions and negative infinity for blocked positions. Scaling by the square root of key dimension controls the magnitude of dot products before normalization. These operations determine the model's information access; they do not establish the truth of an answer.

Foundation model behavior

Autoregressive generation
The model generates one token at a time, conditioning each prediction on the preceding tokens.
Logits
Unnormalized scores for candidate next tokens become probabilities after softmax.
Token probability
This is the model's likelihood of a token in context, not the probability that a claim is true.
Temperature
Dividing logits by a positive temperature changes how concentrated the sampling distribution is.
Top-p
Nucleus sampling keeps the smallest set of highest-probability tokens whose cumulative probability reaches the threshold.
Decoding
A selection rule, such as greedy selection or sampling, turns token scores into an output sequence.
Structured outputs
A declared schema constrains output structure; application checks must still verify values and evidence.
Constrained generation
Restricting allowed next tokens can enforce a grammar without establishing factual correctness.
Test-time compute
Additional inference can generate alternatives or verify results, at a measurable token and latency cost.
Reasoning reliability
Repeated success on controlled cases is stronger evidence than a plausible explanation or agreement among samples.
Uncertainty
Measure uncertainty against labeled outcomes; a model's stated confidence is not automatically calibrated.
Hallucination
A generated claim lacks support or conflicts with evidence, even when its wording is fluent.
Context-window behavior
The window limits token capacity; experiments must test how reliably the model uses evidence inside it.
Positional sensitivity
Move the same evidence within a fixed-length prompt to test whether its position changes accuracy.
Capability boundaries
Identify tasks and input conditions where the model fails, abstains, or needs a different method.
Model selection
Compare models on the actual task using quality, latency, cost and hard safety requirements.

Work through an example

A response is valid JSON and its source_id is a string, so syntax and schema checks pass. The source ID exists, but the cited paragraph describes the previous product revision. Referential integrity passes; support for the current-revision claim fails. Record these outcomes separately and reject the unsupported claim. A single valid=true flag would conceal which boundary failed.

Cheat sheet

From logits to an output contract

Definition

A language model predicts tokens; the application must validate the resulting output.

Intuition

Treat generated text as an untrusted candidate result.

Formula

pi=exp⁡(zi/T)∑jexp⁡(zj/T)p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}

For temperature T greater than zero, scaling logits changes the sampling distribution. Greedy decoding is a separate selection rule.

Common mistake

Schema validity does not prove factual correctness.

Production notes

Record model, prompt, decoding settings and validation failures.
