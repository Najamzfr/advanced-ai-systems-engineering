Test-time compute spends additional inference on candidates, searches, or verification. More samples can expose alternatives, but correlated errors mean majority agreement is not truth. A verifier must check an independently observable property whenever possible. Use arithmetic tests, executable code tests, or source support instead of trusting a convincing rationale.

Freeze cases before changing decoding. Vary temperature, output limit, and inference budget one at a time; record model revision and repeated trials. Position the same necessary evidence near the beginning, middle, and end of a long prompt while holding distractors and total length constant. Measure answer and evidence correctness separately. A larger context window is capacity; positional sensitivity measures utilization. Abstention is an explicit valid outcome when information is absent.

Change the sampling distribution

Keep the logits fixed at 2, 1 and 0. Change temperature and the nucleus threshold to see which tokens remain eligible. This calculation shows selection probabilities, not factual confidence.

pi=exp⁡(zi/T)∑jexp⁡(zj/T)p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}

First apply softmax to the temperature-scaled logits. Keep the highest-probability tokens until their cumulative probability reaches top-p, then renormalize those retained probabilities.

Work through an example

A model is correct on 18/20 short prompts but only 11/20 when the same evidence appears in the middle of a long prompt. Increasing the output limit adds cost without restoring accuracy. The diagnostic points toward context use, not an output truncation problem. Twenty cases are a development diagnostic, not a stable production estimate.

Compare evidence positions

Read the question-answering experiment. Identify the controls that separate positional sensitivity from a larger prompt or different evidence.

Apply the explanation

Five reasoning samples produce the same incorrect answer. Does agreement justify release? Propose a better test.

Read the explanation

No. Shared model assumptions can correlate failures. Verify against a calculation, executable invariant, or independently annotated evidence; compare repeated per-case accuracy and abstention under a fixed total budget.

Cheat sheet

Sampling experiments and reasoning reliability

Definition

A language model predicts tokens; the application must validate the resulting output.

Intuition

Treat generated text as an untrusted candidate result.

Formula

pi=exp⁡(zi/T)∑jexp⁡(zj/T)p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}

For temperature T greater than zero, scaling logits changes the sampling distribution. Greedy decoding is a separate selection rule.

Common mistake

Schema validity does not prove factual correctness.

Production notes

Record model, prompt, decoding settings and validation failures.
