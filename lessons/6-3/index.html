Supervised fine-tuning minimizes loss on target tokens for task examples. Mask prompt/padding tokens as appropriate so the objective matches the intended completion. LoRA keeps a base weight W frozen and learns a low-rank update ΔW=αrBA\Delta W=\frac{\alpha}{r}BA. For a d_out by d_in matrix, rank r adds r(d_in+d_out) trainable parameters instead of d_out*d_in.

QLoRA stores the frozen base in a quantized form while training adapters; low-bit storage does not mean every computation or optimizer state uses the same precision. Other adapters insert small trainable modules. Quantization can also be used for inference independently of adaptation. Track base weights, activations, gradients, optimizer states, and adapters separately. Domain gains can degrade general behavior; evaluate retention and held-out performance after each candidate checkpoint.

Required engineering details

SFT

LoRA
Train low-rank update matrices while freezing the base weights to reduce trainable parameter count.
QLoRA
Train low-rank adapters through a frozen quantized base model while tracking the remaining training memory costs.
Adapters
Add trainable modules to a mostly frozen model to specialize its behavior.
Quantization
Reduce numeric precision to save memory or computation, then measure quality on the intended workload.
Catastrophic forgetting
Adaptation can degrade previously learned capabilities, so evaluate retained tasks as well as the target domain.
Domain adaptation
Adapt behavior to a domain's language and tasks using representative data and held-out tests.
RAG vs fine-tuning
Diagnose whether the failure is missing evidence or unsuitable behavior before choosing retrieval or training.

Work through an example

For a 4096×40964096\times4096 matrix and rank 8, LoRA adds 8(4096+4096)=65,5368(4096+4096)=65{,}536 parameters versus 16,777,216 base parameters, about 0.39% for that matrix. This does not imply the whole training run needs only 0.39% of full memory; activations and other state remain.

A QLoRA run fits the base weights but still runs out of memory on long examples. What should you inspect?

Read the explanation

Activation/attention memory, sequence length, microbatch size, optimizer and adapter state, and checkpointing configuration. Quantizing frozen weights does not remove sequence-dependent memory.

Cheat sheet

SFT, LoRA, QLoRA, and forgetting

Definition

Adaptation changes model behavior through training; retrieval supplies evidence at request time.

Intuition

Diagnose a knowledge problem separately from a behavior or serving problem.

Formula

ΔW=BA,Nadapter=r(din+dout)\Delta W=BA,\qquad N_{\mathrm{adapter}}=r(d_{\mathrm{in}}+d_{\mathrm{out}})

For a LoRA update, B and A have rank r. This count excludes biases and any other trainable parameters.

Common mistake

Training on poor or leaked examples can raise a score without improving the system.

Production notes

Track dataset lineage, splits, retention tests and adapter/model compatibility.
