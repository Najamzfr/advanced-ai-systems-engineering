Hybrid retrieval combines lexical and dense candidates. Raw scores have incompatible scales, so uncalibrated addition can privilege one retriever. Reciprocal rank fusion combines rank positions using a fixed smoothing constant. Preserve stable evidence IDs and deduplicate before reranking. Multi-query RAG fusion combines query variants; it is a different axis from combining BM25 and dense sources.

A cross-encoder reranker jointly scores a query and candidate passage. It can reorder only the candidate pool it receives. Retrieve a larger pool, rerank, then select within the context budget. Apply tenant and permission filters before exposure; test whether post-filtering destroys recall when most candidates are excluded. Record candidate IDs at every boundary to locate where relevant evidence disappeared.

Candidate recall versus reranking

RRF⁡(d)=∑r∈R1k+rank⁡r(d)\operatorname{RRF}(d)=\sum_{r\in\mathcal{R}}\frac{1}{k+\operatorname{rank}_r(d)}

The set R contains ranked result lists. An absent passage contributes zero for that list. The smoothing constant k is distinct from the candidate count.

Inspect reciprocal rank fusion

This example includes both documents in both lists. An absent document contributes zero for that list.

Retrieval

BM25
Rank lexical matches using term frequency, inverse document frequency and document-length normalization.
Inverted indexes
Map each indexed term to the documents or positions where it occurs.
Embedding geometry
Similarity depends on the embedding model, distance function and how the task's text is represented.
ANN
Approximate nearest-neighbor search trades some retrieval recall for faster vector lookup.
HNSW
Navigate a layered proximity graph to find nearby vectors without exhaustively scanning the index.
Vector retrieval
Search embedding similarity to recover related meanings even when wording differs.
Lexical retrieval
Search matching terms, which is useful for exact identifiers, names and uncommon terminology.
Hybrid retrieval
Combine lexical and vector candidates so each method can recover the other's misses.
Reciprocal rank fusion
Combine ranked lists using inverse rank contributions without assuming their raw scores are comparable.
Reranking
Score a retrieved candidate set again with a more expensive relevance model.
Cross encoders
Jointly process a query and candidate passage to estimate their relevance to each other.
Metadata filters
Restrict results by fields such as tenant, document version or date before evidence is used.
Query expansion
Add related search terms while checking that expansion does not change the user's intent.
Multi-query retrieval
Search several formulations of the same question, then merge and deduplicate the results.
HyDE
Embed a generated hypothetical answer to search for real evidence; the generated answer is not itself a source.
Multi-hop retrieval
Use evidence from one retrieval step to formulate the next search needed for the answer.
Contextual retrieval
Add document context to chunks before indexing so isolated passages remain interpretable.

Read the explanation

Measure candidate evidence recall before reranking. Improve source coverage, query formulation, filters, or candidate selection. A stronger reranker cannot recover absent evidence; generation should abstain when support is missing.

Cheat sheet

Hybrid fusion, reranking, and filters

Definition

Fusion combines candidate lists; a reranker scores those candidates against the query.

Intuition

Candidate coverage and candidate ordering are separate decisions.

Formula

RRF⁡(d)=∑r∈R1k+rank⁡r(d)\operatorname{RRF}(d)=\sum_{r\in\mathcal{R}}\frac{1}{k+\operatorname{rank}_r(d)}

The set R contains ranked result lists. An absent passage contributes zero for that list. The smoothing constant k is distinct from the candidate count.

Common mistake

Raw scores from different retrievers are not automatically comparable.

Production notes

Log candidate IDs before and after each stage, and measure latency separately.
