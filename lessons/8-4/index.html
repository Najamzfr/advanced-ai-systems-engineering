Project 2 evaluates 150 scenarios: 30 normal eligible, 30 useful segment/product candidates, 15 misleading product text, 15 contradictory policy, 15 missing data, 15 tool failures, 15 prompt attacks, and 15 ambiguous consent/eligibility. Version case definitions and expected outcomes before running the candidate release. Keep scenario counts distinct from repeated trials.

The chaos matrix includes unavailable model, database, and MCP; malformed output; excessive latency; wrong tool values; poisoned documents; exhausted budget; and missing approval. Measure numeric correctness, grounding, approval compliance, duplicates, recovery, safe escalation, latency, tokens, and reviewer effort. A task may fail safely; report safety and business completion separately.

Work through an example

A wrong tool value has a valid schema. Cross-check deterministic invariants and known fixtures so validation is more than JSON parsing. A model repeating the wrong value faithfully is still an end-to-end data correctness failure.

Cheat sheet

The final chaos and evaluation matrix

Definition

A customer intelligence system turns permission-scoped data into reviewable recommendations.

Intuition

Prediction and an intervention's causal effect answer different questions.

Pattern

Freeze and run the final matrix; preserve raw results, failures, and unexecuted cases without substituting invented success.

Common mistake

A sales correlation does not prove campaign uplift.

Production notes

Keep data lineage, deterministic calculations, approval records and recovery tests.
