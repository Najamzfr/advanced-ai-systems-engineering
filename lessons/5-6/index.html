UCI Online Retail provides transactions, not customer contact addresses, consent, campaign exposures, or conversion labels. Profile missing customer IDs, cancellations, invalid quantities/prices, duplicates, and time coverage. Keep raw records and a documented normalization policy. Use decimal arithmetic or explicit currency precision for money.

Compute recency, distinct invoice frequency, and monetary value at a historical cutoff using only earlier valid purchases. Later transactions can evaluate a ranking proxy, but cannot establish that a campaign caused a purchase. Add explicitly synthetic consent/contact and campaign-policy fixtures. Eligibility is a deterministic tool; the model can propose a draft only after the tool permits it.

Customer C has purchases before and after October 1. Features at October 1 use only earlier transactions. A synthetic consent row can authorize sandbox drafting but is never represented as a real person's consent.

Exercise

Apply the explanation

An offline recommender predicts later purchases well. Can the report claim improved campaign conversion?

Read the explanation

No. Historical transactions have no treatment/control exposure. Report offline predictive performance and reviewer/task metrics; causal uplift requires an appropriate controlled evaluation.

Cheat sheet

Customer data and synthetic policy fixtures

Definition

A customer intelligence system turns permission-scoped data into reviewable recommendations.

Intuition

Prediction and an intervention's causal effect answer different questions.

Pattern

Produce transaction validation, cutoff-safe profiles, synthetic policy/consent fixtures, and the Project 2 threat contract.

Common mistake

A sales correlation does not prove campaign uplift.

Production notes

Keep data lineage, deterministic calculations, approval records and recovery tests.
