Set deadlines across the whole request, not independently at each layer. Retry only when the remaining budget and effect semantics permit it. A circuit breaker stops repeatedly calling a failing dependency and probes recovery; it does not fix the dependency. Rate limits protect fairness, while load shedding rejects work that cannot meet the service promise. Graceful degradation returns a smaller valid result or explicit incompleteness.

Tail latency compounds across dependencies, especially when the task waits for the slowest parallel branch. Measure end-to-end distributions rather than adding component p95 values. Use error-budget consumption to prioritize reliability work and halt risky releases. Define recovery and fallback behavior before failures occur; an untested backup can fail differently from the primary.

Failure handling

SLI

SLO
An internal target sets the acceptable level of a defined service indicator over a stated window.
SLA
An external service agreement states promised behavior and the consequences of missing it.
Tail latency
High percentiles expose slow requests that an average can hide.
Circuit breaker
Stop calls to a failing dependency temporarily, then probe for recovery under controlled conditions.
Fallback
Return an approved alternative or incomplete result when the preferred dependency is unavailable.
Graceful degradation
Reduce functionality explicitly while preserving correctness and permission boundaries.
Rate limiting
Control admission by request or token rate before overloaded work consumes downstream resources.
Load shedding
Reject excess work early so accepted tasks can still meet their deadlines.
Chaos testing
Inject defined failures and check both the expected recovery state and forbidden outcomes.
Failure budgets
Use an SLO's allowed failure count to guide reliability work without treating security violations as acceptable errors.

Work through an example

Five parallel searches are required, and one provider stalls. A per-branch deadline plus a partial-evidence policy lets the task terminate honestly. Waiting forever for all branches defeats the user-level deadline.
