RAG supplies changing external evidence at inference time. Fine-tuning changes model behavior through parameter updates. Prompting and examples can establish an output convention without training. A stale factual answer, inconsistent schema, and excessive latency are different problems; one technique should not be prescribed for all three.

Start with labeled failure slices. If the correct evidence is absent, improve retrieval or tools. If evidence is present but behavior is consistently wrong, compare instructions, demonstrations, and adaptation. If the task passes but misses latency or memory constraints, inspect inference. RAG and adaptation can complement one another, but their combination must justify the extra data, serving, and maintenance cost.

Fine-tuning vs RAG decision framework

ΔW=BA,Nadapter=r(din+dout)\Delta W=BA,\qquad N_{\mathrm{adapter}}=r(d_{\mathrm{in}}+d_{\mathrm{out}})

For a LoRA update, B and A have rank r. This count excludes biases and any other trainable parameters.

Reading

AI Engineering Chapter 7:

When to Fine-Tune
Consider training only after tests show a stable behavior gap that prompting and retrieval do not resolve.
Reasons to Fine-Tune
Repeated format, style or task-behavior errors may justify supervised adaptation with representative examples.
Reasons Not to Fine-Tune
Rapidly changing facts, weak labels or an unmeasured baseline make weight updates a poor first intervention.
Fine-Tuning + RAG
Use retrieval for current evidence and adaptation for stable behavior, then test whether the combination earns its cost.
Quantization
Represent weights or activations with fewer bits and measure the resulting quality and performance changes.
Parameter-Efficient Fine-Tuning
Train a small set of added or selected parameters while retaining most base weights.

Work through an example

A policy assistant needs weekly policy changes and consistent escalation formatting. Retrieval supplies current policy; examples or LoRA may improve the stable escalation behavior. Fine-tuning last month's policy into weights does not create an auditable update mechanism.

Cheat sheet

Diagnose the adaptation problem

Definition

Adaptation changes model behavior through training; retrieval supplies evidence at request time.

Intuition

Diagnose a knowledge problem separately from a behavior or serving problem.

Formula

ΔW=BA,Nadapter=r(din+dout)\Delta W=BA,\qquad N_{\mathrm{adapter}}=r(d_{\mathrm{in}}+d_{\mathrm{out}})

For a LoRA update, B and A have rank r. This count excludes biases and any other trainable parameters.

Common mistake

Training on poor or leaked examples can raise a score without improving the system.

Production notes

Track dataset lineage, splits, retention tests and adapter/model compatibility.
